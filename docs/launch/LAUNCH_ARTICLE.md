# Introducing PATL v0.1 Alpha

Personal AI agents are beginning to act for users. They draft, search, book, send and manage. The missing layer is not another chatbot. It is a trust layer that keeps user authority intact while agents execute bounded tasks.

PATL v0.1 alpha introduces a local reference model:

- PAAC contracts define what an agent may do.
- A deterministic gateway decides allow, log, confirm or block.
- Evidence events record decisions without storing raw private content by default.
- Agent credit is derived from behavior, but never overrides permission.

The alpha includes synthetic demos for email sending, travel purchase limits and scoped file management. It intentionally avoids real accounts and real payments.

PATL is not production-ready. It is a transparent, reproducible starting point for review.
