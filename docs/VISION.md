# Vision

PATL exists to let personal AI agents act without quietly absorbing the user's authority.

The first public position is narrow:

- Users should delegate bounded tasks, not surrender accounts.
- Critical actions must pass deterministic controls.
- Every protected action should produce minimal, reviewable evidence.
- Revocation must be available outside the agent being revoked.
- Agent credit can reduce friction, but can never override permission.

PATL v0.1 alpha demonstrates this through local contracts, local enforcement and synthetic demos. The alpha target is reviewability, not completeness.
