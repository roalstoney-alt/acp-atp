# 90-Day Roadmap

## Days 0-30: Alpha Hardening

- Expand PAAC examples for calendar, contacts and messaging.
- Add canonical JSON signing interface.
- Add local CLI for evaluating action requests.
- Add schema validation without external services.
- Run external security review on threat model and tests.

## Days 31-60: Interoperability Draft

- Define portable authorization bundle format.
- Add verifier for evidence logs.
- Draft third-party auditor profile.
- Add conformance test fixtures for vendors.
- Publish PATL implementer guide.

## Days 61-90: Public Alpha Review

- Freeze PAAC v0.1-alpha compatibility surface.
- Add hardware-vault design appendix.
- Add certification criteria draft.
- Run adversarial review sessions.
- Prepare v0.2 issue backlog from public review.

PATL must not be marketed as production-ready during this period.
