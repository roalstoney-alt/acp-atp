# Responsible Disclosure

PATL v0.1.1 Challenge authorizes only local, defensive testing using synthetic data, mock tools and local fixtures.

It does not authorize attacks against ACP-ATP infrastructure, GitHub, third-party systems, real accounts, production services, payment systems, personal files, credentials or external networks.

If you find a bypass in the local challenge:

1. Record the scenario id or add a new synthetic scenario.
2. Include exact local reproduction steps.
3. Do not include real credentials, live targets, or undisclosed external exploit details.
4. Mark whether the bypass requires breaking the trusted local enforcement boundary.
5. Submit as a defect report or private note before public amplification if the finding creates real-world risk.

Never include real secrets, live credentials, personal data, production logs, exploit payloads for live systems, or instructions for attacking external services.
